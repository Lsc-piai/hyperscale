Webhook 설정 — 외부 서버(piai) 기준

■ 이제 터미널에서 export 할 필요가 없다
  run_server.py 가 kong/.secrets.env (또는 배포 UI 의 환경변수)에서 읽어 B 에 넣어준다.
  토큰은 그 파일로 옮겼다 — 예전에는 이 메모에 평문으로 적혀 있었다.

    kong/.secrets.env 안:
      export PARTNER_WEBHOOK_URL='...'      ← 아직 비어 있다. 아래에서 골라 채울 것
      export PARTNER_WEBHOOK_TOKEN='...'    ← 옮겨둠

  더 안전한 보관처는 배포 UI 의 환경변수다 (pod 이 지워져도 남는다).
  URL 이 비어 있으면 B 는 웹훅 전송만 건너뛰고 나머지는 정상 동작한다.

■ URL 은 환경변수로만 준다
    export PARTNER_WEBHOOK_URL='<파트너가 알려준 수신 주소>'
    export PARTNER_WEBHOOK_TOKEN='<파트너가 발급한 토큰>'

  ★ 이 클러스터는 egress 가 막혀 있을 수 있다(실측: 외부로 나가는 curl 이 timeout).
    보내기 전에 파드에서 그 주소로 나갈 수 있는지 먼저 확인할 것:

      curl -v -m 10 "$PARTNER_WEBHOOK_URL"

  나가지 못하면 "B 의 웹훅 전송 자체는 되는지"를 먼저 가려낸 뒤,
  파트너와 통신 경로를 다시 정해야 한다.
